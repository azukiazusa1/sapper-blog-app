# 表記ルール

筆者が統一している表記です。本文と frontmatter（`about`、`selfAssessment` を含む）で「誤」の列の表記を見つけたら、【誤字脱字・表記ミス】として「正」の列の表記への修正を指摘します。

| 誤   | 正             | 補足                                                                                                   |
| ---- | -------------- | ------------------------------------------------------------------------------------------------------ |
| 部品 | コンポーネント | UI を構成する単位を指す場合。「振る舞いの部品」のように構成要素を指す場合は「構成要素」などに言い換える |
| 既定 | デフォルト     | 「既定値」は「デフォルト値」、「既定の動作」は「デフォルトの動作」にする                               |

コード、コマンド、引用文の中の表記は対象外です。
