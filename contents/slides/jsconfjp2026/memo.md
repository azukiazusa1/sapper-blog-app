### Talk Overview（案）

Gatsby、Next.js、Astro。あなたが知っているあの Web フレームワークの作者たちは、いま揃って AI エージェントフレームワークを作っています。なぜでしょうか？

LLM が流行し始めた当初、TypeScript 製のフレームワークは Python 発の LangChain を模倣し、「処理の流れ（ワークフロー）を組み立てる」ための道具でした。しかしモデルが長時間自律的に動けるようになった今、フレームワークの重心は「エージェントが安全に走り続けるための足場＝ハーネスを用意する」ことへ移っています。ツール、スキル、メモリ、サブエージェント、サンドボックス、Human-in-the-loop、そして耐久性 — 各フレームワークが独立に、同じ構成要素へと収斂しつつあります。

このトークでは、数多くのフレームワークを実際に検証してきた経験をもとに、この転換を10分で駆け抜けます。そして最後に問いに答えます — ハーネスの時代にこそ、型によるツール定義、ファイルベースの規約、Web との接続性という Web フレームワークの知見を継いだ TypeScript が主役になれる、という話を。

エージェントを「使う」から「作る」へ。その一歩目の地図を持ち帰ってください。
